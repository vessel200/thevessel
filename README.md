# Vessel — Personal Portfolio

Static HTML/CSS/JS portfolio designed for GitHub Pages.

## Before publishing
1. Replace `your.email@example.com` in `index.html`.
2. Replace the GitHub and LinkedIn placeholder links.
3. Replace the sample project descriptions with your real projects.
4. Add your real profile photo later if desired.

## GitHub Pages
Upload all files to a repository and enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
